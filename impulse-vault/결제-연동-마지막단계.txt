============================================================
  IMPULSE VAULT — 결제(ExtPay) 연동 "완료" · 확인 체크리스트
============================================================

✅ 진짜 ExtPay 라이브러리가 lib/ExtPay.js 에 들어갔어요.
✅ manifest.json 에 ExtPay 콘텐츠 스크립트(결제 완료 감지) + 권한이 들어갔어요.
✅ 코드(IVPro/background)도 실제 결제 상태를 읽도록 연결됐어요.

이제 아래 두 가지만 확인하면 결제가 진짜로 작동합니다.


────────────────────────────────────────────────────────────
[확인 1] 내 확장 ID 가 맞는지   ← 파일: utils/pro.js
────────────────────────────────────────────────────────────
utils/pro.js 윗부분:

    const EXTPAY_ID = 'impulse-vault';

이 'impulse-vault' 가 ExtensionPay에 "등록할 때 정한 ID"와
정확히 같아야 해요. (ExtensionPay 대시보드 주소
 https://extensionpay.com/extension/<여기가-내-ID> 에서 확인)

다르면 이 줄의 따옴표 안을 내 ID로 바꾸세요. 같으면 그대로 두면 됩니다.


────────────────────────────────────────────────────────────
[확인 2] ExtensionPay 대시보드에서 요금제 설정
────────────────────────────────────────────────────────────
extensionpay.com 대시보드에서:
  • Stripe 연결 완료 확인
  • 요금제(Plan) 추가:  월 ₩3,900 / 연 ₩29,000
  • 무료체험(Free trial): 7일
(가격·체험 기간은 여기서 정하는 게 "진짜" 기준이에요. 앱 화면 문구와
 맞추고 싶으면 utils/pro.js 의 PRICE/ANNUAL/TRIAL_DAYS 도 동일하게.)


────────────────────────────────────────────────────────────
[테스트] 결제가 도는지 확인
────────────────────────────────────────────────────────────
1. chrome://extensions → 개발자 모드 → "압축해제된 확장 프로그램 로드"
2. 대시보드 → Pro 멤버십 → "Pro 시작하기" → ExtensionPay 결제창이 떠야 함
3. Stripe 테스트 카드: 4242 4242 4242 4242 / 미래 만료일 / 아무 CVC
4. 결제 후 잠시 뒤 배지가 PRO 로 바뀌면 성공 ✅
   (결제 완료 → ExtPay가 자동으로 상태를 받아와 Pro로 전환돼요)

문제가 있으면 chrome://extensions 의 "서비스 워커" 콘솔 로그를
캡쳐해서 물어보세요. 같이 봐드릴게요.
