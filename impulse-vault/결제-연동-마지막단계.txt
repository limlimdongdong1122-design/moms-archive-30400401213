============================================================
  IMPULSE VAULT — 결제(Lemon Squeezy) 연동 "마지막 단계"
============================================================

결제는 Lemon Squeezy(레몬 스퀴지)의 "라이선스 키" 방식으로 동작해요.
사용자는 결제 후 받은 라이선스 키를 대시보드에 붙여넣고, 확장 프로그램이
Lemon Squeezy 라이선스 API로 직접 확인(활성화/검증)합니다.
→ 별도 서버·계정·비밀키가 필요 없고, 키는 이 기기에만 저장돼요.

아래 3단계만 하면 진짜로 결제가 작동합니다.


────────────────────────────────────────────────────────────
[1단계] Lemon Squeezy 상품 만들기 + 라이선스 키 켜기
────────────────────────────────────────────────────────────
1. lemonsqueezy.com 에서 Store 생성 (한국 정산 지원, Stripe 불필요).
2. Products → New Product 로 "IMPULSE VAULT Pro" 상품 생성.
   • 구독(Subscription)으로 만들고 가격을 월 $2.99 / 연 $24.99 로 설정.
     (단일 가격만 쓰려면 월 상품 하나만 만들어도 됩니다.)
3. 상품 설정에서 License keys(라이선스 키) 옵션을 켜요(ON).
   • Activation limit(활성화 가능 기기 수)은 1~5 정도 권장.
4. 저장 후 상품의 "Share / Checkout link"(공개 결제 링크)를 복사해 둬요.


────────────────────────────────────────────────────────────
[2단계] 코드에 결제 링크 넣기   ← 파일: utils/pro.js
────────────────────────────────────────────────────────────
utils/pro.js 윗부분 두 상수를 채워요:

    const CHECKOUT_URL = 'https://YOURSTORE.lemonsqueezy.com/buy/REPLACE_ME';
        → 1단계에서 복사한 "결제 링크"로 교체 (필수)

    const LS_PRODUCT_ID = '';
        → (선택) 라이선스가 "이 상품" 것인지 한 번 더 확인하고 싶을 때만
          상품 ID(숫자)를 문자열로 넣어요. 비워두면 이 검사는 건너뜁니다.

가격 문구를 바꾸고 싶으면 같은 파일의 PRICE/ANNUAL 도 맞춰주세요.
(앱 화면 표시는 여기서, "진짜" 청구 금액은 Lemon Squeezy 상품 설정이 기준)


────────────────────────────────────────────────────────────
[3단계] 테스트
────────────────────────────────────────────────────────────
1. chrome://extensions → 개발자 모드 → "압축해제된 확장 프로그램 로드"
2. 대시보드 → Pro 멤버십 → "Get Pro on Lemon Squeezy" → 결제창 열림
   (Lemon Squeezy Test mode 로 먼저 시험 결제해도 돼요)
3. 결제 후 받은 라이선스 키를 "Enter your license key" 칸에 붙여넣고
   Activate(활성화) 클릭.
4. 잠시 뒤 상태가 Pro 로 바뀌면 성공 ✅
   • 해지/환불/만료되면 다음 검증 때 자동으로 무료로 돌아가요.
   • 무료 기능(BYOK + 규칙 기반 스코어카드)은 해지해도 계속 사용 가능.

문제가 있으면 chrome://extensions 의 "서비스 워커" 콘솔 로그를
캡쳐해서 물어보세요. 같이 봐드릴게요.
