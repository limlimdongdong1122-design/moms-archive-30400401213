============================================================
  IMPULSE VAULT — 결제(PayPal) 연동 "마지막 단계"
============================================================

결제는 PayPal로 받고, "라이선스 키"로 Pro를 풀어줘요.
PayPal은 키를 자동으로 안 주기 때문에, 우리가 직접 서명된 키를 발급해요.
  • 키는 비밀키(LICENSE_SECRET)로 HMAC 서명됩니다.
  • 비밀키는 오직 Cloudflare Worker 안에만 있어요 (확장 프로그램엔 없음).
  • 확장 프로그램은 키를 Worker에 보내 진위만 확인해요. (서버/DB/계정 불필요)
  • 같은 키를 관리형 AI 호출에도 같이 보내서, 진짜 Pro 사용자에게만
    당신의 API 비용이 쓰이게 막아줘요.

아래 4단계면 결제가 진짜로 작동합니다.


────────────────────────────────────────────────────────────
[1단계] PayPal 결제 링크 만들기
────────────────────────────────────────────────────────────
PayPal Business 계정에서:
  • "Pay Links / Buttons"(결제 링크/버튼) 또는 구독 버튼 생성
  • 가격: 월 $2.99 또는 연 $24.99 (원하는 것)
  • 만들어진 공개 결제 링크(URL)를 복사해 둬요.


────────────────────────────────────────────────────────────
[2단계] Cloudflare에 비밀키 설정   ← Worker가 키를 검증하는 열쇠
────────────────────────────────────────────────────────────
Cloudflare → Pages 프로젝트 → Settings → Variables and Secrets:
  • LICENSE_SECRET = (아주 긴 랜덤 문자열)   ← 타입: Secret
  • ANTHROPIC_API_KEY = sk-ant-...           ← 타입: Secret (AI용)
LICENSE_SECRET 값은 [4단계] 키 생성 때도 똑같이 써야 해요. 잘 보관!


────────────────────────────────────────────────────────────
[3단계] 코드에 결제 링크 넣기   ← 파일: utils/pro.js
────────────────────────────────────────────────────────────
utils/pro.js 윗부분:

    const CHECKOUT_URL = 'https://www.paypal.com/REPLACE_ME';
        → [1단계]에서 복사한 PayPal 결제 링크로 교체 (필수)

    const LICENSE_API = 'https://impursivevault.com/api/license';
        → 사이트 도메인이 다르면 본인 도메인으로 (보통 그대로 두면 됨)

가격 문구를 바꾸려면 같은 파일의 PRICE / ANNUAL 도 맞춰주세요.


────────────────────────────────────────────────────────────
[4단계] 결제 들어오면 → 키 발급해서 메일 보내기
────────────────────────────────────────────────────────────
PayPal로 결제가 들어오면, 터미널에서 키를 한 개 만들어요:

  연간 키:   IV_LICENSE_SECRET="2단계의그비밀키" node tools/make-license.cjs --year
  월간 키:   IV_LICENSE_SECRET="..."             node tools/make-license.cjs --month
  평생 키:   IV_LICENSE_SECRET="..."             node tools/make-license.cjs --lifetime

출력된 키(IVP-...)를 구매자에게 이메일로 보내요.
구매자는 대시보드 → Pro 멤버십 → 키 붙여넣고 Activate(활성화) → 끝!


────────────────────────────────────────────────────────────
[테스트]
────────────────────────────────────────────────────────────
1. 위 명령으로 테스트 키 하나 생성
2. chrome://extensions → 개발자 모드 → "압축해제된 확장 프로그램 로드"
3. 대시보드 → Pro 멤버십 → 키 붙여넣고 Activate
4. 상태가 PRO 로 바뀌면 성공 ✅
   • 만료되면 다음 확인 때 자동으로 무료로 돌아가요.
   • 무료 기능(BYOK + 규칙 기반 스코어카드)은 해지/만료해도 계속 사용 가능.

💡 나중에 자동화하고 싶으면: PayPal 웹훅(IPN) → Worker가 키를 자동 발급/메일
   발송하도록 확장할 수 있어요. (지금은 수동 발급이라 런칭 초기엔 충분)

문제가 있으면 chrome://extensions 의 "서비스 워커" 콘솔 로그를
캡쳐해서 물어보세요. 같이 봐드릴게요.
