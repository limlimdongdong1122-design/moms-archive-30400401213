============================================================
  IMPULSE VAULT — 결제(ExtPay) 연동 "마지막 단계" 안내
============================================================

스트라이프 + ExtensionPay 연동을 마치셨다면, 이 폴더는 결제까지
딱 "두 줄"만 손보면 라이브됩니다. (둘 다 1분이면 끝나요)


────────────────────────────────────────────────────────────
[1단계] 내 확장 ID 넣기   ← 파일: utils/pro.js
────────────────────────────────────────────────────────────
utils/pro.js 를 메모장으로 열고, 윗부분에서 이 줄을 찾으세요:

    const EXTPAY_ID = 'impulse-vault';

따옴표 안의 'impulse-vault' 를, ExtensionPay에 등록할 때 정한
"내 확장 ID"로 바꾸세요. (ExtensionPay 대시보드에서 확인 가능)

    예)  const EXTPAY_ID = '내가-정한-아이디';

※ 등록할 때 'impulse-vault' 그대로 쓰셨다면 안 바꿔도 됩니다.


────────────────────────────────────────────────────────────
[2단계] 진짜 ExtPay.js 로 교체   ← 파일: lib/ExtPay.js
────────────────────────────────────────────────────────────
지금 lib/ExtPay.js 는 "임시 파일(스텁)"이라 결제가 안 됩니다.
아래에서 진짜 라이브러리를 받아 이 파일을 통째로 덮어쓰세요.

받는 곳 (둘 중 하나):
  • ExtensionPay 대시보드의 ExtPay.js 다운로드, 또는
  • 브라우저로 아래 주소를 열고 "다른 이름으로 저장":
    https://raw.githubusercontent.com/Glench/ExtPay/master/dist/ExtPay.js

받은 ExtPay.js 파일로  lib/ExtPay.js  를 덮어쓰기 하면 끝.


────────────────────────────────────────────────────────────
[확인] 잘 됐는지 테스트
────────────────────────────────────────────────────────────
1. chrome://extensions → 개발자 모드 → "압축해제된 확장 프로그램 로드"
   로 이 폴더를 불러오기 (또는 다시 zip으로 묶어 웹스토어 업로드)
2. 대시보드 → Pro 멤버십 → "Pro 시작하기" → 결제창이 뜨면 성공
3. 스트라이프 테스트카드: 4242 4242 4242 4242 / 미래 만료일 / 아무 CVC
4. 결제 후 배지가 PRO로 바뀌고 "데모" 토글이 사라지면 완료 ✅

문제가 있으면 두 파일(utils/pro.js, lib/ExtPay.js)을 그대로 캡쳐/복사해
물어보세요. 같이 봐드릴게요.
