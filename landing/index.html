설치할 때 파란 경고창이 떠도 놀라지 마세요

"Windows의 PC를 보호했습니다" 라는 파란 창이 뜰 수 있어요. 이건 바이러스 경고가 아니라, 아직 유료 코드 서명 전이라 Windows가 처음 보는 앱에 띄우는 일반 안내예요. 아래 2번만 누르면 바로 설치돼요. 👇

  1. 받은 IMPULSE-VAULT-Setup.exe 를 두 번 클릭해요.
  2. 파란 창이 뜨면 → 가운데의 “추가 정보(More info)” 글씨를 클릭.
  3. 아래에 나타나는 “실행(Run anyway)” 버튼을 클릭.
  4. 설치 마법사가 열리면 다음 → 설치 로 진행하면 끝! 🎉
