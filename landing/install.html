브라우저에 추가하기

아직 크롬 웹스토어 심사 전이라, 지금은 파일을 받아서 직접 추가해요. 크롬·엣지·웨일·브레이브 등 크로미움 계열 브라우저에서 동작해요. (30초면 끝!)

확장 프로그램 다운로드 (.zip) 받은 zip은 꼭 압축을 풀어 주세요.
  1. 위 버튼으로 받은 zip을 압축 해제해요. (impulse-vault 폴더가 나와요)
  2. 확장 관리 페이지를 열어요 — 주소창에 본인 브라우저의 주소를 입력 → 엔터:
    Chrome chrome://extensions Edge edge://extensions Brave brave://extensions Whale whale://extensions Opera opera://extensions Vivaldi vivaldi://extensions
  3. 개발자 모드를 켜요. (Chrome·Brave·Whale·Vivaldi는 오른쪽 위, Edge·Opera는 왼쪽 토글)
  4. 압축해제된 확장 프로그램을 로드(Load unpacked) 버튼 → 방금 푼 impulse-vault 폴더 선택.
  5. 설치 완료! 처음 한 번 온보딩 화면에서 감시할 사이트와 권한을 허용하면 끝이에요.
안심하세요 🔒 — IMPULSE VAULT는 검색·상품·구매 기록을 어떤 서버로도 보내지 않아요. 모든 분석은 브라우저 안(로컬)에서만 이뤄져요. "개발자 모드" 경고는 웹스토어 정식 등록 전이라 뜨는 일반적인 안내예요.
