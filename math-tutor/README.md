# 📐 중3-1 수학 튜터 (모바일 웹앱)

문제를 입력하면 **정답 + 단계별 풀이**를 한국어로 자세히 알려주는 수학 튜터입니다.
휴대폰 브라우저에서 바로 열어 쓸 수 있도록 **순수 HTML/JavaScript**로 만들었습니다. (설치·인터넷 불필요)

## 다루는 단원 (중3-1)

| 단원 | 기능 | 예시 입력 |
|------|------|-----------|
| 제곱근의 계산 | 근호 정리 | `√72` → `6√2` |
| 곱셈 공식 | 전개 | `(2x+1)^2` → `4x²+4x+1` |
| 인수분해 | 인수분해 | `2x^2+7x+3` → `(2x+1)(x+3)` |
| 이차방정식 | 풀이(인수분해+근의공식+판별식) | `x^2-5x+6=0` → `x=2, 3` |
| 이차함수 | 꼭짓점·축·절편·최대최소 | `y=x^2-4x+3` |

## 휴대폰에서 여는 법

1. **가장 쉬운 방법** — `math-tutor/index.html` 파일을 휴대폰으로 옮겨 브라우저로 열기
   (카카오톡 "나에게 보내기" 등으로 파일 전송 → 열기)
2. **GitHub Pages / 정적 호스팅** — `math-tutor/` 폴더를 정적 사이트로 배포하면 URL로 접속
3. PC에서 미리 보려면: `cd math-tutor && python3 -m http.server 8000` → 브라우저에서 `localhost:8000`

> 홈 화면에 추가하면 앱처럼 전체화면으로 쓸 수 있어요. (모바일 브라우저 → 공유 → 홈 화면에 추가)

## 입력 표기 규칙

- 거듭제곱: `^` 사용 — `x²` 는 `x^2` (또는 화면의 `x²` 키)
- 곱셈: `2x`, `3(x+1)`, `(x+1)(x-1)` 처럼 붙여 써도 자동 인식
- 제곱근: `√12` 또는 화면의 `√` 키
- 등호 `=` 가 있으면 방정식으로 인식

상단의 **단원 칩**(자동/제곱근/전개/인수분해/이차방정식/이차함수)을 누르면
원하는 방식으로 강제 지정할 수 있고, `자동`은 입력을 보고 스스로 판단합니다.

## 구성 파일

- `index.html` — 모바일 화면(UI). 입력창 + 단원칩 + 보조 키패드 + 풀이 카드
- `engine.js` — 계산 엔진. 브라우저와 Node 양쪽에서 동작 (분수 정확 계산, 단계별 풀이 생성)
- `tutor.py` — (참고용) PC 터미널에서 쓰는 파이썬 버전. sympy 기반.

## 엔진 단독 테스트 (개발자용)

```bash
cd math-tutor
node -e 'const E=require("./engine.js"); console.log(E.solve("x^2-5x+6=0"))'
```
