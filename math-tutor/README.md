# 📐 수학 튜터 (Math Tutor)

모르는 수학 문제를 입력하면 **정답 + 단계별 풀이**를 한국어로 자세히 설명해 주는 프로그램입니다.
sympy로 실제 계산을 수행하므로 손계산 실수 없이 정확한 답을 줍니다.

## 설치

```bash
pip3 install sympy
```

## 실행

```bash
# 대화형 모드 (문제를 계속 입력)
python3 tutor.py

# 한 문제만 바로 풀기
python3 tutor.py "solve x^2 - 5x + 6 = 0"
```

## 지원하는 문제 종류

| 명령어      | 설명          | 예시 |
|-------------|---------------|------|
| `solve`     | 방정식 풀기    | `solve 2x + 3 = 7` |
| `system`    | 연립방정식     | `system x+y=3; x-y=1` |
| `diff`      | 미분          | `diff x^3 + sin(x)` |
| `integrate` | 부정적분       | `integrate x^2 + 3x` |
| `defint`    | 정적분         | `defint x^2 from 0 to 2` |
| `limit`     | 극한          | `limit sin(x)/x as x to 0` |
| `factor`    | 인수분해       | `factor x^2 - 5x + 6` |
| `expand`    | 전개          | `expand (x+1)^3` |
| `simplify`  | 식 정리        | `simplify (x^2-1)/(x-1)` |
| `evaluate`  | 값 계산        | `evaluate 2^10 + sqrt(144)` |

명령어를 생략하면 자동으로 추측합니다. (`=` 있으면 방정식 등)

## 표기 규칙

- 거듭제곱: `^` 또는 `**`  → `x^2`, `x**2` 둘 다 가능
- 곱셈: `2x`, `3(x+1)` 처럼 붙여 써도 자동으로 `2*x`, `3*(x+1)` 로 해석
- 함수: `sin`, `cos`, `tan`, `log`, `exp`, `sqrt` 등 sympy 표준 함수 사용
- 무한대: `oo` 또는 `inf`

## 예시 출력

```
$ python3 tutor.py "solve x^2 - 5x + 6 = 0"

============================================================
  방정식 풀이
============================================================

① 주어진 방정식:  x² - 5·x + 6 = 0
② 모든 항을 좌변으로 이항 (우변 = 0 꼴): x² - 5·x + 6 = 0
③ 이것은 x에 대한 2차 방정식입니다.
④ 좌변을 인수분해: (x - 3)·(x - 2) = 0
⑤ 각 인수를 0으로 두고 풉니다 (AB=0 ⇒ A=0 또는 B=0).
⑥ 따라서 해는: x = 2,  x = 3
⑦ 검산: x=2 → 0 OK / x=3 → 0 OK

  ✅ 최종 정답: [2, 3]
```
