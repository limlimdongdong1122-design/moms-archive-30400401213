# 🛰️ PRICE SCOUT — 경쟁사 가격 정찰

**셀러를 위한 조용한 가격 정찰병.**
경쟁사 상품을 추가해두면, 자는 동안에도 가격 변동을 정찰하고 알려줍니다.

## 무엇인가요?

쿠팡 · 네이버 스마트스토어 · 11번가 · G마켓 등에서 파는 **셀러를 위한 경쟁사 가격
모니터링 크롬/엣지 확장 프로그램**입니다. 감시하고 싶은 경쟁 상품 페이지에서 버튼 한 번이면
추적이 시작되고, PRICE SCOUT가 주기적으로 가격을 다시 확인합니다.

셀러 관점에서 가격 변동의 의미는 정반대입니다 — 그래서 색으로 구분합니다:

| 경쟁사 움직임 | 의미 | 색 |
| ------------- | ---- | -- |
| 가격을 **내림** ▼ | **언더컷 위협** — 내 매출을 빼앗길 수 있어요 | 코랄 `#ff7b6b` |
| 가격을 **올림** ▲ | **가격 기회** — 내 가격을 올리거나 가격 우위를 굳힐 틈 | 민트 `#2fe0a6` |

내 판매가를 입력해두면 경쟁사가 나보다 싼지/비싼지 한 줄로 비교해줍니다.

## 핵심 기능

- **원클릭 추적** — 상품 페이지 우측 하단의 정찰 버튼 한 번이면 끝.
- **자동 백그라운드 정찰** — `chrome.alarms`로 주기적으로 페이지를 다시 읽어 가격을 갱신.
- **언더컷 즉시 알림** — 가격이 움직이면 데스크톱 알림 + 툴바 배지. 위협(언더컷)은 우선순위 높음.
- **내 가격 대비 비교** — 내 판매가를 넣으면 "내 가격보다 ₩2,000 쌈/비쌈"을 즉시 표시.
- **가격 추이 스파크라인** — 각 상품의 최저·최고·현재가와 미니 차트.
- **100% 로컬** — 사용자 데이터는 어떤 서버로도 전송되지 않습니다. 추적 목록·기록·설정은
  전부 `chrome.storage.local`에만 저장됩니다.
- **무료 5개 · Pro 무제한** — 결제 SDK를 붙일 수 있는 Pro 플래그 내장(데모 토글 제공).

## 어떻게 동작하나요? (아키텍처)

```
┌─────────────────────────────────────────────────────────────┐
│  content/tracker.js   ← 상품 페이지에서 실행 (Shadow DOM 위젯)  │
│      └ utils/adapters.js  : DOM에서 이름/가격/이미지 추출        │
│      └ utils/price.js     : 순수 가격 계산                      │
│                          │  PS_TRACK_ADD / PS_UPDATE_PRICE     │
│                          ▼                                     │
│  background.js (MV3 서비스워커) ── 메시지 라우터 + 스케줄 정찰    │
│      └ fetch(상품 URL) → adapters.extractFromHtml() (정규식)    │
│      └ price.classifyForSeller() → 알림 / 배지 / 기록           │
│      └ utils/storage.js   : 단 하나의 저장소 writer            │
│                          ▲                                     │
│      popup / dashboard / onboarding  ← chrome.runtime 메시지로  │
│                                         상태 조회·변경           │
└─────────────────────────────────────────────────────────────┘
```

설계 원칙 몇 가지:

- **저장소 writer는 하나** — 모든 UI는 `background.js`에 메시지를 보내고, 저장은 `storage.js`만 합니다.
- **MV3 서비스워커엔 DOM이 없습니다** — 그래서 백그라운드 정찰은 `DOMParser` 대신 **정규식**으로
  HTML을 파싱합니다 (JSON-LD → `og:price` 메타 → 내장 JSON 가격 키 → `₩/원` 텍스트 순).
- **순수 로직은 테스트로 보호** — 가격이 "움직였는지, 얼마나, 셀러에게 좋은지 나쁜지"를 정하는
  `utils/price.js`는 의존성 없는 노드 테스트로 검증합니다.

## 설치 (개발자 모드)

1. `chrome://extensions` (또는 엣지 `edge://extensions`)에서 **개발자 모드**를 켜세요.
2. **압축해제된 확장 프로그램을 로드** → 이 `price-scout/` 폴더를 선택하세요.
3. 경쟁사 상품 페이지를 열면 우측 하단에 정찰 위젯이 뜹니다. 추가해보세요.

> 폰트는 선택입니다. `fonts/README.md`를 참고해 `.woff2`를 넣으면 의도한 타이포가 적용되고,
> 없으면 시스템 폰트로 깔끔하게 폴백됩니다.

## 개인정보

PRICE SCOUT는 분석·추적·계정이 없습니다. 외부로 나가는 네트워크 요청은 **당신이 직접 추가한
상품 페이지를 읽는 GET** 뿐입니다. 대시보드의 _내 데이터 · 개인정보_ 탭에서 저장된 내용을
모두 확인하고, JSON으로 내보내거나, 한 번에 삭제할 수 있습니다.
